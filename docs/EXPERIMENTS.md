|---|---|

## 최종안에서 제외하거나 제한한 시도

- Grounding DINO 기반 Targeted SoM과 crop verifier는 반복 검증에서 counting 성능이 악화돼 최종 적용에서 제외했습니다.
- 수평 반전과 더 많은 TTA가 항상 좋은 결과를 주지 않아 원본 768px 추론을 제한된 비율로 결합했습니다.
- 검증에서 가장 좋은 조합과 public에서 가장 좋은 조합이 달랐습니다. 모델 크기나 단일 검증 점수만으로 채택하지 않았습니다.

## 최종 재학습

Gold 5,073개와 고신뢰 dev pseudo-label 902개, 총 5,975개를 사용했습니다. Seed 43, 684 optimizer updates로 학습한 후 640/768 추론 확률을 결합했습니다.

기존 검증 데이터가 이 학습에 포함되므로 이후 같은 검증셋의 수치는 학습 내 평가입니다. Private 5위는 본인 확인 기록이고, public 0.94994는 최종 확인 제출 기록입니다.

## 중복 이미지 후처리

학습·개발 데이터의 참조 답이 질의 선택지에 있고 이미지 dHash가 일치하며 정규화 질문 유사도가 0.70 이상일 때 후보를 사용했습니다. 최종 앙상블에는 기본 8B 예측에서 답을 바꾸는 개입만 전달했습니다. 당시 최종 test에서 개입은 3개였습니다. 대회 데이터의 접근 권한과 이용 조건을 확인한 환경에서 후보를 재계산해야 합니다.
