# 평가 조건과 결과

## 단일 모델의 학습 전후 비교

| 항목 | 조건 |
|---|---|
| 모델 | `Qwen/Qwen3.5-9B` |
| 검증 데이터 | `train.csv` 마지막 10%, 508문항 |
| 학습용 gold 데이터 | 앞 90%, 4,565문항 |
| 입력 | 512px 이미지와 동일한 질문·선택지 프롬프트 |
| 추론 | 다음 답변 토큰의 a/b/c/d 확률로 정답 선택 |
| 추가 학습 | vision·language LoRA, gold + 선별한 dev 의사 라벨 |
| 체크포인트 선택 | 검증 정답 수 우선, 동률이면 정답의 negative log-likelihood가 낮은 epoch |

학습 전후에 저장한 검증 출력 `qwen35_zero_valid.csv`, `qwen35_tuned_valid.csv`를 비교했습니다. 두 파일의 문항 ID·순서·이미지 경로·질문·선택지·정답이 모두 일치함을 확인했습니다. 문항별 데이터와 예측은 제외하고 집계 결과만 정리했습니다.

| 구분 | 정답 / 전체 | 정답률 |
|---|---:|---:|
| Zero-shot | 429 / 508 | 84.45% |
| LoRA 학습 후 | 474 / 508 | 93.31% |
| 차이 | +45 / 508 | +8.86%p |

학습 후 오답에서 정답으로 바뀐 문항은 57개, 정답에서 오답으로 바뀐 문항은 12개입니다. 정답 수의 순증가는 45개입니다.

**평가 범위:** 체크포인트 선택에 사용한 검증셋에서 학습 전후의 개선을 비교했습니다. 독립 테스트 성능을 뜻하지는 않습니다. 이후 전체 gold 데이터로 재학습한 모델과 최종 앙상블의 성능은 이 비교에 포함하지 않았습니다.

구현은 [512px 학습 노트북](../notebooks/02_Qwen3_5_9B_512_VQA.ipynb)의 데이터 분할, zero-shot 평가, epoch별 검증, 학습 후 평가 셀에서 확인할 수 있습니다.
